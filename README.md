# Heart Attack Risk Prediction (Demo)

A small, runnable demo that estimates the **probability of heart-attack risk**
for each patient from routine clinical features, and exports a risk report.
The demo is sex-aware: it includes **menopause status for women** and reports
model performance **separately for men and women**.

> **Disclaimer:** The dataset in this repository is **synthetic** (generated by
> `generate_data.py`). No real patient data is used. This demo is a decision-support
> prototype, **not a medical device**, and must not be used for diagnosis or treatment.

## What it does

1. Loads a patient table (1,000 rows, 15 features, 180 missing cells).
2. Applies menopause rules (men = not applicable; missing values in women are inferred from age).
3. Imputes remaining missing values (median for numeric, most-frequent for categorical).
4. Scales numeric features and one-hot encodes categorical features.
5. Trains a Logistic Regression model on 80% of patients (split stratified by outcome and sex).
6. Predicts a risk probability (0-100%) for the held-out 20% of patients.
7. Assigns a risk level (Low < 30%, Medium 30-60%, High >= 60%).
8. Prints overall metrics plus a men-vs-women breakdown (AUC, observed vs predicted rate).
9. Saves `risk_report_demo.csv`.

## Files

| File | Purpose |
|------|---------|
| `heart_risk_demo.py` | Main script: preprocessing, training, evaluation, risk report |
| `patients_demo.csv` | Synthetic patient dataset (with injected missing values) |
| `generate_data.py` | Script that generates the synthetic dataset |
| `risk_report_demo.csv` | Example output of the demo run |

## Data dictionary

| Column | Description |
|--------|-------------|
| `patient_id` | Anonymous identifier (not used as a feature) |
| `age`, `sex` | Demographics |
| `menopause_status` | premenopausal / postmenopausal (women); not_applicable (men) |
| `chest_pain_type` | typical_angina / atypical_angina / non_anginal / asymptomatic |
| `resting_bp` | Resting blood pressure (mmHg) |
| `cholesterol` | Serum cholesterol (mg/dl) |
| `fasting_blood_sugar` | 1 if fasting blood sugar is high, else 0 |
| `resting_ecg` | normal / st_t_abnormality / lv_hypertrophy |
| `max_heart_rate` | Maximum heart rate achieved during exercise |
| `exercise_angina` | 1 if exercise induces angina |
| `st_depression` | ST depression induced by exercise |
| `smoker`, `bmi`, `family_history` | Lifestyle / history |
| `heart_attack` | Target: 1 = event, 0 = no event |

## How to run

```bash
pip install pandas numpy scikit-learn
python generate_data.py      # optional: regenerate the dataset
python heart_risk_demo.py
```

## Demo result

ROC-AUC is about 0.76 overall (men ~0.71, women ~0.83 on small subgroups).
Because the data is synthetic, these numbers only show that the pipeline works;
they say nothing about clinical accuracy.

## Demo limitations (available in the full version)

- Single baseline model; no model comparison or hyperparameter tuning
- Only the held-out 20% of patients is scored
- No cross-validation or probability calibration
- No per-patient explanations (e.g. SHAP)
- Outcome is not a time-bound (e.g. 10-year) risk, and predictors are not
  aligned with standard calculators (ASCVD Pooled Cohort Equations, PREVENT)
- No saved model, REST API, dashboard or PDF reports

## Roadmap to a usable product

1. Replace synthetic data with real, consented, de-identified data
2. Define a time-bound outcome and use standard predictors (HDL, LDL, BP treatment, diabetes, eGFR)
3. Compare models (Logistic Regression, Random Forest, Gradient Boosting)
4. Cross-validation, calibration (per sex) and external validation
5. Explainability for each prediction
6. REST API (FastAPI) and a simple clinician dashboard
7. Privacy, security and regulatory review before any clinical use
